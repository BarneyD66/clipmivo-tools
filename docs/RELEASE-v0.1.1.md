# Developer tools v0.1.1

This release synchronizes downloadable packages with the Credit-first documentation and application integration guide.

- CLI 0.2.7 and MCP 0.1.8 include updated setup and billing documentation; runtime behavior is unchanged except version reporting.
- The clipmivo-video Skill package now includes Credit budgets, quote confirmation, reserved-credit settlement and existing budget authorization guidance.
- Install links point to this release. All clients connect to https://clipmivoai.com/api/v1.
- Applications use server-side keys and share account-level balances and resources. Reseller subaccounts and revenue sharing are not implemented.

The public repository contains client tools and documentation. Website deployment is managed separately.
